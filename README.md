# bike
## 1. サービス概要（※最後に書いてOK）

- このサービスはどんなサービスか（3行以内）
　- バイクに乗る人目線でよかった場所などを投稿機能で投稿して、それを見たほかのバイク乗りがその場所を目的地に設定する。をお互いに繰り返してバイク乗り同士の目的地がない問題を解決するサービスです。

- 誰の、どんな課題を、どう解決するか
　-バイクに乗りたいけれど、大体有名な観光スポットは行きつくしてしまって、行きたい目的地が見つからなくなってバイクに乗るモチベーションがなくなった人が、すぐにバイカーの意見に沿った形で投稿機能を閲覧し、行きたいと思う目的地を探すことができ、バイクに乗りたいけど目的地がないという悩みを解決するためのアプリです。
---

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情


自分自身が幼いころから親の影響もあり、バイクに興味があり社会人になってバイクの免許を取得しました。そして免許を取りたての頃は周りの友達などもバイクを乗っていたりで一緒に地元の定番スポットや改めて観光をしに行ったりしていたのですが、環境が変化していく中で、周りの人たちがバイクから離れていき、バイク自体は好きなのにモチベーションが下がりつつありました。バイクに乗ることは好きなのに行く場所がなかったりするのはもったいないと感じていました。そこがアプリを作ろうと思ったきっかけです。

---

同じ体験をしても、気にしない人もいます。
**なぜ自分はそれが気になったのだと思いますか？**

- 自分の性格
- 過去の経験
- 大切にしている価値観

など結びつけて考えてみてください。

好きな人はおそらくおんなじ場所を何度も行ったりして、バイクに乗りたての新鮮味というか高揚感みたいなのが薄まっていると思う。自分の性格的にはおそらく何があっても乗り続けたいと思うし飽きてもしばらくしたらどうせ乗りたくなってる。そこが自分と違う人たちも毎回少しでもいいから違った景色、行ったことない道路などを知るきっかけになればいいと思う。

## 3. 課題の整理（表面的になっていないか）

### 3-1. 表に見えている困りごと

その体験の中で、最初に感じた「困りごと」は何ですか？

バイク自体には乗りたいのに、乗る目的地がないし探すのがそもそも面倒で、それよりも行動にかかるコストに負けてしまって、結局バイクに乗らなくなる。

---

「なぜそれが困るのか？」を**最低3回**繰り返してください。

- なぜ？
- なぜ？
- なぜ？

目的地がないので困る
行先の候補が大体固定化されていて、飽きてくる。新しい場所を見つけたい。
目的地の楽しさももちろん、車では気づけないような「道中の楽しさ」を体感したい。

→ 本当に解決したい課題:バイクに乗りたいときにしっかり自分が行きたいと思えるような目的地を毎回設定できるような状態にしたい。

  - 環境：休日に特に予定がなくてバイクに乗ろうと思っているが目的地が決まっていない。

  　　　　・その思い立った瞬間じゃなくても仕事の休憩時間などにアプリを閲覧していて、いい場所があったから今度バイクで行ってみよう見たいな状態を作りたい。
  　　　　・目的地が常にあるような状態を作り、バイクに乗りたいという欲求を消化できることで目的地がない状態をなくしていきたい。

※最低1つは必ず書いてください。

このアプリが**うまくいかない可能性**と、
それに対して**どう向き合おうとしているか**を書いてください。

### 懸念点①

- 何が問題になりそうか：
  投稿の質が低くなりすぎるという点。

- なぜそう思うか：
  投稿の質のハードルを低くするのは狙いではありますが、スポットとして成立しないレベルだと投稿の意味があんまりないと思うから。

- そのために考えている対策：
  閲覧数で並び替えや、ほかのユーザーからのリアクションみたいなもので質が低すぎるものに関してはあんまり映らないようにする。

### 10-3.キャッチアップ不足の懸念

キャッチアップ不足の段階では以下の懸念点があります。
1. **完成までのハードルが高い**
使用する言語やフレームワークが異なるため、キャッチアップにかかる時間は個人差があるものの、一定の時間を要することが予想されます。
2. **Issueの見積もりが難しい**
「どこまで理解していて、何が分からないのか」「調査にかかる時間」などが不明瞭な場合、開発期間内に完了することが難しくなってしまいます。
